## 📚 What's inside

| Folder | Contents |
| --- | --- |
| `C/` | C fundamentals — loops, arrays, conditionals, lab exercises |
| `C++/` & `C++ New/` | C++ basics — calculators, loops, conditionals, age-group logic |
| `JAVA/` | Intro Java programs |
| `Leetcode/` | LeetCode solutions (e.g. island problems) |
| `Python/` | Python practice + a small `Flaskweb` app, plotting, OOP, lambdas, file I/O |
| `ML/` | ML experiments — linear/logistic/polynomial regression, KNN, plotting |

Plus standalone explorations like `Customerstaisfaction.ipynb` (customer-satisfaction analysis) and a small `game.js`.

## 🎯 Purpose

This repo tracks my learning journey across languages and paradigms — from first "hello world" programs to regression models and DSA problem-solving. It's intentionally broad: a record of consistent, hands-on practice.
